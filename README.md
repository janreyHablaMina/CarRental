# CarRental — DriveX

A luxury car rental web application built with **Next.js 16**, **React 19**, **Tailwind CSS**, and interactive canvas-based 360° scroll animation.

![Next.js](https://img.shields.io/badge/Next.js-16-black?style=for-the-badge&logo=next.js)
![React](https://img.shields.io/badge/React-19-blue?style=for-the-badge&logo=react)
![TailwindCSS](https://img.shields.io/badge/TailwindCSS-v4-38bdf8?style=for-the-badge&logo=tailwindcss)

---

## 🌟 Key Features

- **360° Cinematic Supercar Scroll**: Seamless 240-frame sequence with custom physics-based lerp damping and zero-flicker double-buffered rendering.
- **Interactive HUD Telemetry**: Real-time chapter and frame telemetry synchronized with scroll position.
- **Dynamic Vehicle Fleet**: Browse sports cars, sedans, SUVs, and luxury rentals with instant specs.
- **Streamlined Booking Workflow**: Interactive date pickers, pickup/dropoff selection, and category filters.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile displays with parallax mouse effects.

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for production

```bash
npm run build
npm run start
```
